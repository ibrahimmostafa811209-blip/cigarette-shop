إدارة محل السجائر - نسخة PWA تجريبية

الملفات:
- index.html: واجهة البرنامج
- manifest.json: إعدادات التثبيت على الشاشة الرئيسية
- sw.js: التخزين المؤقت للعمل دون اتصال بعد أول فتح ناجح
- icon.svg: أيقونة التطبيق

طريقة النشر المقترحة: ارفع الملفات الأربعة إلى مستودع GitHub ثم فعّل GitHub Pages من Settings > Pages واختر Deploy from a branch ثم main و / (root). افتح رابط Pages الناتج من Chrome بعد الاتصال بالإنترنت، انتظر التحميل، ثم قائمة Chrome > Install app أو Add to Home screen.

تنبيه: هذه النسخة تخزن البيانات محليًا في المتصفح على الجهاز. لا تحتوي على مزامنة سحابية بين الأجهزة. احتفظ بنسخ احتياطية ولا تستخدمها كدفتر الحسابات الوحيد قبل اختبارها.

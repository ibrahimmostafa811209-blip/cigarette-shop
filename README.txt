نظام إدارة محل السجائر - النسخة المطورة

الرفع على GitHub Pages: ارفع محتويات مجلد docs إلى مجلد docs الموجود في المستودع واستبدل الملفات القديمة بعد حفظ نسخة احتياطية من البيانات. تأكد من اختيار Branch main والمجلد /docs في Settings > Pages.

الميزات: أصناف ومخزون وأسعار جملة وقطاعي وفواتير ومشتريات وعملاء وديون ومصروفات وتقارير يومية وشهرية وخزنة وإعدادات مدير ونسخ احتياطي.

مهم: البيانات محلية على كل جهاز. المزامنة التلقائية بين أجهزة متعددة تحتاج ربط خدمة سحابية، وهي غير مفعلة في هذه النسخة. لا تمسح بيانات المتصفح، واحتفظ بنسخ JSON احتياطية.
